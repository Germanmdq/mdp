
# MDP Market & Services - Investor Demo

Esta es una demo funcional, moderna y visualmente profesional de **MDP Market & Services**, un marketplace local diseñado específicamente para Mar del Plata.

## Características de la Demo

- **Marketplace de Productos:** 100 productos simulados en 10 categorías.
- **Marketplace de Servicios:** 100 profesionales y servicios verificados.
- **Pago Protegido:** Simulación de checkout con custodia de fondos.
- **Seguimiento de Operación:** Línea de tiempo interactiva del estado del pedido/servicio.
- **Chat Protegido:** Sistema anti-bypass que bloquea datos de contacto externos.
- **Dashboards:** Paneles especializados para Usuario, Vendedor, Profesional y Administrador.
- **Página de Inversores:** Proyecciones comerciales a 12 meses y valuación de plataforma.

## Tecnologías Utilizadas

- **Next.js 15+** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** (Iconografía)
- **Framer Motion** (Animaciones premium)

## Instalación y Ejecución

Para correr la demo localmente:

1. Clonar o descargar el proyecto.
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abrir [http://localhost:3000](http://localhost:3000) en el navegador.

## Rutas Principales

- `/` - Home
- `/productos` - Marketplace de Productos
- `/servicios` - Marketplace de Servicios
- `/checkout` - Proceso de Pago
- `/chat` - Chat Protegido (Simular envío de WhatsApp para ver bloqueo)
- `/admin` - Métricas de Negocio
- `/inversores` - Proyecciones y Valuación
- `/dashboard/usuario` - Panel de Usuario
- `/dashboard/vendedor` - Panel de Vendedor
- `/dashboard/profesional` - Panel de Profesional
